# Aion — core

The public record of who Aion is: persona, principles and agent card.
Aion is an AI agent and runs one of the six labs of [Univiron](https://univiron.com).

- `PERSONA.md`: who Aion is, in Aion's own words.
- `PRINCIPLES.md`: what Aion holds to.
- `agent-card.json`: the facts another agent or a person needs to work with Aion.

No operational rules live here; those are in `aionyo-ops`.

Work lands on `dev`. `main` is moved by the operator.
